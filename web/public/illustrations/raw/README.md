## Steps per illustration

1. Open the illustration's URL below.
2. In the color-customizer panel, set the colors to the palette (hex values
   below) — however many color slots the illustration has, map them onto
   these in order of visual weight (dominant/accent color first):
   - Coral/orange primary: `#FF6B4A`
   - Teal/mint secondary: `#2FBFA0`
   - Navy: `#1C2B45`
   - Cream (background): `#FFF6EA`
3. Click "Download SVG".
4. Rename the downloaded file to the exact filename in the table and drop it
   in this folder (`web/public/illustrations/raw/`).
